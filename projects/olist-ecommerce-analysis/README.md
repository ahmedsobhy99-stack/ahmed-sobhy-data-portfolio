# Olist E-Commerce Sales Analysis

## Project Overview
This project analyzes Brazilian e-commerce data from Olist to understand business performance, customer behavior, delivery operations, product performance, and payment patterns.

The project was developed using Power BI to transform raw data into interactive dashboards and actionable business insights.

## Dashboard Pages

### Page 1 — Executive Overview
An overview of key business performance indicators, sales trends, and overall e-commerce performance.

### Page 2 — Customer & Sales Analysis
An analysis of customer behavior, purchasing patterns, and sales performance to support better business decisions.

### Page 3 — Operations & Performance
An overview of operational performance and relevant business metrics to help identify improvement opportunities.

## Tools & Skills
- Power BI
- Data Cleaning and Transformation
- Data Modeling
- DAX Measures
- Data Visualization
- Business Intelligence

## Dataset
The project uses the Olist Brazilian E-Commerce public dataset.
