# Start here

This is a starter repository for Ahmed Sobhy's Data Analyst / Sales Analyst GitHub portfolio.

## Before publishing

1. Review `README.md` and correct any dates, titles, or tool names that need confirmation.
2. Add only public, synthetic, or explicitly approved project files.
3. Replace project placeholders with actual questions, methods, screenshots, and verified findings.
4. Add your GitHub profile URL and any public Power BI portfolio link.
5. Check every file for confidential data and credentials before pushing.

## Suggested GitHub setup

1. Sign in to GitHub and create a **public** repository named `ahmed-sobhy-data-portfolio` (or your preferred name).
2. Upload the contents of this folder to the repository root, or use Git locally.
3. Ensure the top-level `README.md` appears on the repository home page.
4. Add project files gradually, starting with the Amazon project if its dataset and files are shareable.
5. Pin the repository on your GitHub profile.

GitHub is the portfolio host here; this README is a repository landing page, not a separate deployed website.
